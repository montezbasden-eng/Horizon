## [Claude AI Uncovers Origins of NIST ECDSA Curve Seeds](https://www.anthropic.com/research/ecdsa-curve-origins) ⭐️ 9.0/10

Anthropic's Claude AI discovered that the seeds for the NIST ECDSA curves (P-192, P-224, P-256, P-384, and P-521) were generated using the C library's lrand48 random-number generator seeded with Unix timestamps, solving a decades-old cryptographic mystery. This discovery debunks long-standing conspiracy theories that the NSA deliberately weakened the curves, potentially restoring trust in widely used cryptographic standards and demonstrating AI's capability to solve complex reverse-engineering problems in cryptography. The seeds were generated over a period of months, and while the method is confirmed, it does not rule out the possibility that curves were selected for specific properties by searching over timestamps; additionally, the fifth binary seed (B-163) remains unexplained, possibly due to a typo in the published value.

hackernews · ahlCVA · Oct 16, 18:55 · [Discussion](https://news.ycombinator.com/item?id=50122800)

**Background**: ECDSA (Elliptic Curve Digital Signature Algorithm) is a widely used public-key cryptography standard based on elliptic curves. The NIST curves were standardized in FIPS 186-2 in 2000, and their seeds were supposedly generated by hashing an arbitrary seed with SHA-1, but the origin of the seeds was unknown, leading to speculation about NSA involvement. lrand48 is a pseudo-random number generator from the C standard library that uses a linear congruential algorithm with 48-bit arithmetic.

## [Llama.cpp runs natively on jailbroken PS5, enabling GGUF model inference](https://github.com/cobanov/PS5LM) ⭐️ 8.0/10

A new project called PS5LM (hosted on GitHub by cobanov) enables native execution of GGUF models via llama.cpp on a jailbroken PlayStation 5, turning the console into a low-cost LLM inference device. The project leverages recent PS5 jailbreak exploits to run the open-source llama.cpp runtime directly on the console's hardware. This demonstrates that a locked-down consumer appliance can be repurposed as a general-purpose LLM inference machine, potentially offering a cheap alternative for long-running AI tasks. It highlights the growing trend of running local LLMs on unconventional hardware and could inspire similar efforts on other consoles or cut-down hardware. The project runs quantized GGUF models, with community reports indicating it can handle models like Qwen 3.8 27B at 2-bit quantization, making it viable for tasks requiring a constant token stream. Power consumption is estimated at around 70 cents per day, yielding roughly 2 million output tokens daily.

hackernews · Anon84 · Oct 16, 18:32 · [Discussion](https://news.ycombinator.com/item?id=50122431)

**Background**: GGUF is the standard file format for distributing quantized large language models for local inference, natively supported by tools like llama.cpp, Ollama, and LM Studio. Llama.cpp is a C++ runtime that executes these models efficiently on CPUs and optional accelerators without Python dependencies. Jailbreaking a PS5 involves exploiting security vulnerabilities to bypass Sony's restrictions, allowing the installation of custom software. Recent exploits like 'Relapse' have made jailbreaking possible on most firmware versions, enabling projects like this one.

## [Claude redesigns quantum circuits for up to 17x fewer operations](https://www.anthropic.com/research/designing-efficient-quantum-circuits) ⭐️ 8.0/10

Anthropic demonstrated that Claude, working largely on its own, redesigned eight simulated quantum circuits to use up to 17x fewer operations, improving on the best published versions in some cases by an order of magnitude or more. This is a notable AI-for-science result showing LLMs can perform verifiable optimization in a closed-loop setting, potentially reducing resources needed for quantum algorithms and inspiring further automation of circuit design. The work builds on Google's Kickmix language, an assembly-like language for classically simulatable quantum circuits, where optimization resembles code golf; however, commenters note that in some cases Claude removed components needed only for extremely rare inputs, raising correctness trade-offs.

hackernews · pretext · Oct 16, 18:00 · [Discussion](https://news.ycombinator.com/item?id=50121939)

**Background**: Quantum circuits are sequences of quantum gates that perform computations; optimizing them by reducing gate count or depth is crucial for running algorithms on near-term quantum computers. Kickmix is a low-level language for expressing such circuits that can be simulated on classical computers, enabling rapid testing. LLMs like Claude can generate and refine code, and when combined with a verifier that checks correctness, they can iteratively improve solutions.
