## [OpenAI's Jalapeño Chip Sets New AI Inference Speed and Efficiency Records](https://openai.com/index/jalapeno-first-results) ⭐️ 9.0/10

OpenAI announced the first results of its custom inference chip, Jalapeño, developed with Broadcom, showing industry-leading speed and efficiency for AI inference. The chip outperformed current state-of-the-art processors on SemiAnalysis' InferenceX benchmark, delivering more tokens per user and more throughput per kilowatt. This marks a significant shift in the AI hardware landscape, as OpenAI, a major AI model provider, moves to custom silicon to reduce costs and improve performance. It could challenge NVIDIA's dominance in AI inference and influence the broader ecosystem's infrastructure choices. Jalapeño is a custom inference chip built for LLM inference, focusing on higher throughput and lower latency for modern models. The chip's die size is about the same as NVIDIA's Rubin, but it delivers roughly one-third the NVFP4 PFLOPs, according to community analysis of the comparison table.

**Background**: AI inference is the process of running trained models to make predictions, and it is becoming a major cost factor in AI deployment. Custom inference chips, such as Google's TPU and Amazon's Inferentia, are designed to optimize this workload, offering better performance per watt than general-purpose GPUs. OpenAI's entry into this space with Broadcom aims to scale AI systems more efficiently.

## [FDA Authorizes First Wearable for Continuous Ketone and Glucose Monitoring](https://www.fda.gov/news-events/press-announcements/fda-authorizes-first-wearable-device-continuously-monitors-both-ketone-levels-and-blood-sugar) ⭐️ 8.0/10

The U.S. Food and Drug Administration (FDA) has authorized the Libre Duo 10 Day Continuous Dual Glucose Ketone Monitoring System, the first wearable device that continuously monitors both ketone levels and blood sugar. This authorization applies to people aged 2 years and older with diabetes. This milestone could significantly improve diabetes management by enabling early detection of diabetic ketoacidosis (DKA), a potentially fatal condition. It also paves the way for more integrated metabolic health monitoring, benefiting patients and advancing health technology. The device is the same size as Abbott's FreeStyle Libre 3 sensor, the world's smallest and thinnest CGM sensor. It received breakthrough device designation from the FDA during development, highlighting its novelty and potential impact.

hackernews · sunnynagra · Aug 25, 19:07 · [Discussion](https://news.ycombinator.com/item?id=49439017)

**Background**: Continuous glucose monitors (CGMs) measure glucose levels in interstitial fluid, providing real-time data for diabetes management. Ketones are chemicals produced by the liver when the body uses fat for energy; elevated levels can lead to diabetic ketoacidosis (DKA), a serious complication. Previously, no wearable device could continuously monitor both metrics simultaneously, requiring separate tests for ketones.

The M6 is Apple's first 2nm chip with a 12-core CPU, 12-core GPU, and Dual 16-core Neural Engine, while the M5 Ultra is Apple's first quad-die architecture and its most powerful chip ever. This announcement marks a significant leap in performance and AI compute for Apple's silicon, potentially accelerating on-device AI capabilities across Mac products. The M5 Ultra uses a quad-die architecture by connecting two dual-die M5 Max chips via UltraFusion technology, offering up to 256GB RAM and 16TB storage in the Mac Studio, with a 512GB RAM version expected in October.

## [EVE Online Begins Long-Awaited Migration from Stackless Python 2.7 to Python 3](https://simonwillison.net/2026/Aug/25/eve-online-move-to-python-3/) ⭐️ 8.0/10

EVE Online has officially announced the start of its migration from Stackless Python 2.7 to Python 3, a process that will use the futurize script on 2.4 million lines of code and involve manual review of approximately 20,000 behavioral differences between Python 2 and 3. This migration is significant because EVE Online is one of the largest and longest-running Python codebases in production, and its successful transition will provide valuable insights for other large-scale Python projects facing similar upgrades. It also highlights the ongoing industry-wide shift away from Python 2, which reached end-of-life in 2020. The migration will rely on the futurize script, which automates the conversion of Python 2 code to a Python 2/3 compatible form, but the team will also manually review the ~20,000 places where behavior differs, such as integer division. The announcement does not specify how they will replace Stackless Python, but a previous conference talk described using the open-source carbonengine/scheduler library in their newer game EVE Frontier.

rss · Simon Willison · Aug 25, 22:59

**Background**: Stackless Python is an alternative Python implementation that adds microthreads (tasklets) for lightweight concurrency, avoiding the overhead of OS threads. EVE Online has used Stackless Python since its launch in 2003, with its last major upgrade to Stackless Python 2.7 in 2010. Python 2 reached end-of-life in January 2020, and the Stackless Python project itself has been officially discontinued, making this migration necessary for long-term maintenance and security.
